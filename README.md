# Smart Health UI

This deliverable includes two implementations of the provided 5-page UI sample:

- `web/` - Vite + React web app
- `mobile/` - Expo + React Native mobile app

All screen text is placeholder copy and follows the same dark health-tech theme, page order, and core layout from the PDF.

## Run Web

```bash
cd web
pnpm install
pnpm dev
```

## Run Mobile

```bash
cd mobile
pnpm install
pnpm start
```
